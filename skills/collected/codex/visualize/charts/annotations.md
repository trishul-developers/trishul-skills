# Annotations

All options inside spec; single measure, no grouping. References/points: line,area,bar,horizontalBar,scatter. Uncertainty bars: line/bar/horizontalBar/scatter; band:line only. No arbitrary layers/second axis/inferred statistics. Reference axis names the physical dimension: y for vertical values, x for horizontalBar. Numeric x lines for line/scatter; line also exact category, ISO time between observations, or between:[anchorA,anchorB] with fraction0–1 default.5 and no value. Anchors each unique; supplied event timing only. If timing missing show chart without marker and note it, no waiting. Category/time line X refs incompatible with logX/numeric xDomain; no category/time X bands.
Numeric references finite original coordinates, band from<to, positive on log; automatic domains expand, explicit domains must include references/intervals. Max8 lines+8 bands, labels≤160chars. Fixed bands are not rowwise uncertainty.
Point field actual measure, at exact supplied category/X (Y for horizontal bars) matching one row. Repeated X uses unique stable spec.rowId + annotation rowId instead; string/numeric distinct, no both selectors; verify IDs, absent/filtered omits, never relocates. No inferred peaks/interpolation. Max8 annotations, unique nonempty IDs≤100chars, labels≤160. Best-effort placement may put full label in note; dense permanent attached labels/custom connectors/positions need fallback.
Uncertainty lower/upper distinct fields of absolute bounds, not ±distance; every observed row finite lower≤measure≤upper, unique X/category, positive lower on logY. Missing line y/lower/upper all explicit null; bar/scatter cannot be missing. Keep supplied endpoints; label supplied meaning/confidence (≤160chars), otherwise Interval. Tooltips show estimate/endpoints. No grouped/stacks/X/area/sparkline uncertainty; never omit required bounds.
